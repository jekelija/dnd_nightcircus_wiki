# Curses Through the Ages

**Held by:** [[candace-cheeks|Candace Cheeks]]

## Description

A book stolen by Candace from the restricted section of the [[trollbottom-institute|Trollbottom Institute]] library during Session 2. It contains a section on breaking binding curses — a massively complex process requiring obscure ingredients. It yielded no leads on tattoos, potions, or memory magic.
